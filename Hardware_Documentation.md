Introduction  
Smart City Connect is a platform that simulates smart cities by combining software and IoT concepts. The prototype shows how hardware devices can work with web applications in actual smart city settings.  

Project Overview  
The project covers transportation, energy management, public safety, environmental monitoring, and smart services.  

Hardware Architecture  
The prototype includes sensors, controllers, communication modules, and output devices that collaborate to create a smart city ecosystem.
